Head of IT

Solution Architect · main session
Opus
  • Talks to you, writes the spec (1 page).
  • Delegates to the right agent, merges only after PASS.
  • Runs npm run check, reports cost in plain words.
Done: spec approved, merged after PASS, board current, cost reported.

ux-designer

Product Designer
Opus
  • Owns the look — one design system (docs/DESIGN-SYSTEM.md).
  • One visual mockup per new screen, BEFORE any code.
  • Reviews built screens against the mockup.
Done: mockup approved by you, then the built screen matches it.

builder

Backend Engineer
Sonnet
  • Rust core: money, stock, GST, crash safety, database.
  • Bill save = one SQLite transaction, gap-free numbers.
  • Tests for every rule; no unwrap/expect.
Done: builds to spec, npm run check green, tests pass.

ui-builder

Frontend Engineer
Sonnet
  • React screens, exactly to the approved mockup + tokens.
  • Keyboard-first; every action has a key.
  • Takes a screenshot before finishing.
Done: screen matches the mockup (screenshot), typecheck/lint/test green.

verifier

QA · Release Gate
Opus
  • Reads the diff vs spec + design, runs every test.
  • Tries to break it: empty bill, huge qty, kill mid-save.
  • PASS or FAIL — FAIL blocks merge, no exceptions.
Done: PASS (or a short FAIL list with file:line).
